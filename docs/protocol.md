# 单位、坐标系与双板协议

> 两块板、三个层次都以此为准。**改任何一项都必须同步改另一块板。**

---

## 一、单位约定（全工程唯一口径）

| 物理量 | 符号 | 单位 | 说明 |
|---|---|---|---|
| 线速度 | vx, vy | m/s | 平移，定义在**云台坐标系** |
| 角速度 | w | rad/s | 绕 z 轴，**逆时针为正**（z 向上、右手法则） |
| 关节角度 | yaw, pitch | rad | yaw 可连续旋转，pitch 受限位约束 |
| 角度差 | δ, error | rad | 一律先过 `robot::WrapToPi()` |
| 电机角度 | `angle()` | rad | 输出端（已含减速比） |
| 电机角速度 | `vel()` | rad/s | 输出端 |
| 轮子线速度 | — | m/s | 由轮半径换算成角速度后进速度环 |
| 轮速环输出 | — | 报文原始量 | ±16384 对应 ±20 A |
| 云台环输出 | — | N·m | DM-J4310 上限 7.5 N·m |

**易错点**：「半轮距 L/2」指**左右**方向（y），「半轴距 W/2」指**前后**方向（x）。
本工程分别叫 `half_track` / `half_wheelbase`，二者之和就是自旋力臂。

---

## 二、坐标系

- **云台系**：x = 云台朝向（枪管），y = 云台左方，z = 上
- **车体系**：x = 车头朝向，y = 车体左方，z = 上
- **约定**：所有平移指令 (vx, vy) 一律定义在云台系，`vx > 0` 永远是「操作手面对的方向」

变换（`robot::GimbalToChassis()`，`module_state.hpp`）：

```
δ  = 云台朝向 − 车头朝向    （取云台 yaw 关节角，经 G2C 帧送到底盘板）
vx_c = vx_g·cos δ + vy_g·sin δ
vy_c = −vx_g·sin δ + vy_g·cos δ
```

**只转一次**：`Chassis::SetCommand()` 存 δ → `Chassis::Update()` 调
`ChassisIkSolver::SolveAndLimit()` 内部完成旋转 + 逆解。

**唯一需要实车确认的是符号**：推杆发现方向反了，只改 `kFrameDeltaSign`（取 −1），
不要动任何调用点。

## 三、CAN ID 全表

| 用途 | ID | 方向 | 说明 |
|---|---|---|---|
| M3508 控制（ID 1~4） | `0x200` | 底盘板 → 电调 | 4 台一帧，每台 2 字节 |
| M3508 控制（ID 5~8） | `0x1FF` | 底盘板 → 电调 | 本车未确认是否使用 |
| M3508 反馈 | `0x201`~`0x208` | 电调 → 底盘板 | `0x200 + id` |
| DM-J4310 发送 | `0x01`~`0x0F` | 云台板 → 电机 | = 电机 ID |
| DM-J4310 反馈 | `0x11`~`0x1F` | 电机 → 云台板 | = 电机 ID + 0x10 |
| **C2G（底盘→云台）** | **`0x210`** | 跨板 | 本工程选定 |
| **G2C（云台→底盘）** | **`0x211`** | 跨板 | 本工程选定 |

## 四、双板帧（8 字节，两个方向共用同一结构）

### 字节布局

| 字节 | 字段 | 类型 | 缩放 | C2G | G2C |
|---|---|---|---|---|---|
| 0 | flags | uint8 | — | bit0 在线 / bit1 就绪 / bit2 急停 | 同 |
| 1 | mode | uint8 | — | bit0~1 底盘模式，bit2~3 云台模式 | 同 |
| 2~3 | yaw | int16 小端 | ×1000 | 期望 yaw（实为归一化摇杆速率） | 实际关节角 |
| 4~5 | pitch | int16 小端 | ×1000 | 期望 pitch（同上） | 实际关节角 |
| 6 | aux | int8 | ×20 | `w_des` | `yaw_vel` |
| 7 | seq | uint8 | — | 帧序号，判断丢帧 | 同 |

量程与精度：

- 角度：±32767/1000 = ±32.7 rad（≈ ±5.2 圈），分辨率 0.001 rad ≈ 0.057°
- 辅助量：±127/20 = ±6.35 rad/s，分辨率 0.05 rad/s

### 枚举取值（两板必须一致）

| 枚举 | 取值 |
|---|---|
| `LifeState` | 0=Dead, 1=Resurrection, 2=Working |
| `ChassisMode` | 0=分离, 1=跟随, 2=小陀螺 |
| `GimbalMode` | 0=关节空间 |
| `ControlSource` | 0=无, 1=遥控器 |

### 离线判断

阈值 `kCommOfflineThresMs = 100 ms`，判据 `now - last_rx_tick_ > 100`。
拔线后约 100 ms 置位，另一板进 Dead 并全零输出。

### 字段语义的一处有意偏离

`yaw_des/pitch_des` 名义上是「期望云台目标角」，实际传的是**归一化摇杆速率**
（因为接收机接在底盘板上，云台板读不到 DBUS）。这是有意设计，
**答辩时要主动说明**，否则会被当成字段用错。

## 五、遥控器映射

| 输入 | 作用 |
|---|---|
| 左摇杆竖直 | 前后平移（云台系 vx） |
| 左摇杆水平 | 左右平移（云台系 vy，右推为 −y） |
| 右摇杆水平 | 分离模式原地转向；云台模式下控 yaw 转速 |
| 右摇杆竖直 | 云台模式下控 pitch 转速 |
| 拨轮 | 小陀螺自旋角速度（有限幅） |
| **左拨杆 Down** | **急停：所有电机立即归零** |
| 右拨杆 Up / Mid / Down | 分离 / 跟随 / 小陀螺 |

### ⚠️ 档位必须实测

DBUS 只传「开关值 1/3/2」，**不传语义**。DJI Phantom 系列遥控器标注
（`OFF/CL/HL`、`GPS/ATTI/ATTI`）与 DT7 完全不同，不能照搬上表。

做法：拨到每一档读 `rc_l_switch_ / rc_r_switch_`，把实测映射记进
[parameters.md](parameters.md) 的记录表，并同步修改本文档。
