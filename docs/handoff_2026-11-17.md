**CAN 拓扑（实测）**：CAN1 = 两块板 + yaw 达妙（反馈 `0x012`）+ 双板帧 `0x210/0x211`；
CAN2 = 四个 C620（`0x201~0x204`）+ pitch 达妙（`0x011`，目前仍静默）。
轮速指令 `0x200`/`0x1FF` **两路都发**。达妙 ID：yaw=2、pitch=1。

**DBUS（已定案，别再猜）**：帧长 **18 字节**、**无 0x20 帧头**、间隔 **14 ms（71.4 帧/秒）**、
块内**偏移 0**。USART3，100 kbaud / 9 位 / 偶校验。用 `ReceiveToIdle` 按空闲切块，
每块直接当一整帧校验。详见 `known_issues.md` 5.1。

**这台遥控器的特殊之处**：没有独立三档拨杆，`byte5` 高 4 位恒为 `0xF`（拨杆字节恒 `0x0303`）。
所以：

| 功能 | 实现 |
|---|---|
| 急停 | **左摇杆竖直 ≤ -0.9**（卡住位置是 -1.0） |
| 三模式 | **右摇杆竖直拨一下切一档**（>0.75 触发，回中 <0.45 解锁；分离→跟随→小陀螺循环） |
| 云台 yaw | 右摇杆横向（**分离模式下不再驱动底盘转向**） |
| 云台 pitch | 右摇杆竖直，\|rv\| ≤ 0.5 时 |
| 小陀螺自旋 | 拨轮 |

## 二、当天修掉的 6 个 bug（都在 `known_issues.md` 第 5 节有详细版）

1. **DBUS 判据**：`acc |= data[i]` 判"整帧全 FF"是错的（`0xF5|0xFA == 0xFF` 会误杀合法帧）→ 逐字节判。
2. **DBUS 接收**：18 字节定长在窗口错位后永不重同步 → 改 `ReceiveToIdle`。
3. **武装互锁**：写成了"任一摇杆偏转就清零指令" → 一推杆轮子就停。改成一次性上锁。
4. **CAN 自恢复**：`AutoBusOff = DISABLE` 让一次 bus-off 变成永久静默 → 两板四路改 ENABLE。
5. **左右轮镜像**：`kWheelDir` 四个都写 `kDirRev`，前推变原地转 → 右侧 RB/RF 改 `kDirFwd`。
6. **轮速环**：静摩擦门槛实测 raw 655~819，`ff=400` 不够（起步延迟 0.2 s）；目标为 0 时积分冻结
   导致残余爬行 → `ff=800 / kp=250 / ki=200`，目标为 0 时清积分并输出 0。

## 四、小陀螺（Spin）：已解决，机理如下

### 4.1 最终行为（2026-11-17 晚实测通过）

- 拨轮控自旋；**平移方向随枪口**（`g_ignore_delta = 0` + `kFrameDelta()` 模式区分）
- 自旋 + 平移时**不再被闸门削速**（闸门 0.75 覆盖最坏情况 0.707）
- 自旋时前进方向**不再偏 15°**（`g_frame_lead` 补偿）
- 静态（不自旋）平移方向本来就准，补偿在 ω=0 时恒为 0，不影响

### 4.2 三个诊断量（下次出问题先量这三个）

在自旋过程中录：`command_.w`、四轮 `vel_`（M3508 对象 +0x08）、`delta_`。
固件里已经内置录制（见 4.4），不用在线读。

### 4.3 实测数据与结论（2026-11-17 一次 7 s 录制）

| 量 | 实测 | 判读 |
|---|---|---|
| `command_.w` | 全程 −0.793 恒定 | 拨轮/DBUS 没问题 |
| 四轮 `vel_` | 3.18 rad/s，目标 3.13（误差 0.23） | 轮速环跟得住 |
| 轮速环 `out` | 峰值 661 / 3000（22%） | **没有饱和**，"提 out_max" 无意义 |
| 底盘实际自旋 | 1.370 rad/s = 指令的 **1.71 倍**；峰值 2.51 倍（1.16 s） | 见下 |
| `delta_` 斜率 vs IMU | **−1.370 vs −1.370**（小数点后三位一致） | 云台**完美保向** |
| 枪口绝对朝向（IMU yaw + δ） | 自旋全程只漂 **−3.1°** | **云台不是"角力"** |
| 轮速 jitter（1 ms 级） | 最大 1.87 | **没有两颗电调同 ID 的特征** |

**结论（重要，别再走回头路）**：

1. **"云台保向力矩把车拖停"这个假设是错的**。云台确实在顶（1 N·m），但轮速环只需 22% 就压住它，
   而且枪口绝对朝向只漂 3°。
2. **"提底盘自旋权限"对纯自旋无效**：纯自旋 0.8 rad/s 只需 0.245 m/s，本来就碰不到闸门；
   它只在"自旋+平移"时咬住（0.245+0.15=0.395 > 0.3），那才是加闸门的真正理由。
3. **15° 方向偏**的机理：平移按"下发那一拍的 δ"解算，但整车把速度做出来要 ~0.2 s，
   这 0.2 s 里底盘又自转 ω·τ → **实际走的方向 = R(ω·τ) × 枪口方向**。
   实测 ω=1.37 时偏 15° = 0.26 rad → τ≈0.19 s。符号随 ω 翻、整条斜线、静态不偏 —— 三个特征都对上。
   修法：`δ_eff = δ − g_frame_lead·ω`（ω 取底盘 IMU 的 yaw 角速度，`Imu::yawRate()`）。
4. **平移"有点慢"**：0.3 的闸门把 0.395 等比削到 0.76。提到 0.75 后不再削。
5. **还有一个没解决的比例问题**（1.71 倍），见第五节，它不影响方向和功能，只影响"标称速度是否等于实际"。

### 4.4 内置录制与导出（出问题先跑这个）

- 固件：`robot.cpp` 的 `g_trace_*`，1 kHz 控制周期里按 **100 Hz** 采 21 列 × 7 s，
  进小陀螺且 |w|>0.2 自动触发，**只写 RAM，不参与控制**
  （列：t/模式/w_cmd/δ/四轮目标/四轮实际/四轮 out/四轮 jitter/IMU yaw）
- 跑的时候 SWD 可以拔掉；跑完插上：
  `pwsh -File tools\jlink.ps1 -Action dump-trace -Board chassis -Speed 200`
- 判读：`python tools\spin_trace.py --dump spin_trace.bin --plot spin_trace.png`
  （直接输出 4 条判据：指令是否衰减 / 轮子是否跟住 / 车是否打滑 / 是否有反馈跳变）
- `dump-trace` 会自动把 `g_trace_state/n` 清零，下一次拨轮就能重录

### 4.5 `g_frame_lead` 怎么调

| 现象 | 做法（J-Link 写 float 位模式，不用重编） |
|---|---|
| 方向正对枪口 | 保持 0.19 |
| 还偏，但比原来小 | 增大（0.19 → 0.25…） |
| 偏到反方向 | 写负值（−0.19） |

补偿量 = `g_frame_lead × ω`，ω 是**实测**转速（不是指令），所以自旋档位变了也自动跟。
上限钳在 ±0.6 rad（34°），防 IMU 异常时把平移拧飞。

## 六、调试方法与坑（血泪版）

1. **符号地址每次编译都会变**，读内存前必须重新 `nm`；`GetRobot()::robot` 前面有
   `guard variable for ...`，正则要用 `名称$` 并排除 `guard`。
2. **J-Link `connect` 会 halt CPU**，halt 期间读到的计数是冻结值；判断"程序在跑"要两次读 `uwTick`。
   长时间 halt 会被 IWDG 复位，所以在 halt 后先 `w4 0xE0042008 0x1000` 冻结看门狗。
   **连不上时 J-Link 会自动试 "connect under reset"，可能把板子复位、把 RAM 里的录制清掉** ——
   录制完先确认 SWD 插好再连。
3. **SWD 现在很脆**：1 MHz 经常 `Failed to initialize DAP`，降到 200 kHz 通常能通。
   `tools/jlink.ps1` 已支持 `-Speed 200`（脚本里不再写死速度）。落地跑之前把 SWD 拔掉。
4. **运行期变量断电即丢**：`g_force_mode / g_estop_force / g_ignore_delta / g_delta_offset /
   g_frame_lead / g_follow_* / g_wheel_* / g_yaw_*` 都是 RAM。调好的值要写回代码默认值。
5. **改代码只用 edit 工具**，别用 PowerShell 拼文本（曾把文件写成 1 行）。
   改完先 `arm-none-eabi-g++ -fsyntax-only` 自检（include/define 从 `build/w/build.ninja` 抄）。
6. **判断方向只能靠物理观察**（麦轮看不出前后），但"相对符号图案"可以远程判：
   前进 = 四轮同号；自转 = 左右反号；横移 = 对角同号。
7. **不要用台架开环调速度**：开环是恒流无速度环，4% 不动、5% 直接冲到 20 rad/s。只用于点动判方向。
8. **判据要唯一**：这次"云台角力"的假设就是被 `delta_` 斜率 + IMU 绝对朝向这一对数据否掉的，
   不要靠现象猜（见 `known_issues.md` 4.5）。

## 七、安全红线（不可越）

- 云台 `max_torque` 现为 1.0 N·m（曾因 `ki=8` + 1.0 N·m 失控飞转）。**`ki` 必须保持 0**，
  积分限幅 ±0.15，`|err| > 34°` 清积分 —— 这三条是抑制飞转的关键，不要动。
- 任何参数调整都要先**静置 30 秒观察输出是否稳定**，再谈响应速度。
- 落地测试：车架空先验方向 → 落地低速 → 手不离急停（左摇杆到底）。
- `g_ignore_delta`、`g_force_mode`、`g_estop_force` 正式使用前必须是 0
  （`g_ignore_delta=1` 会让"平移随枪口"失效）。
- 闸门 `kMaxWheelVelMps` 是最后一道限幅，**提它之前先确认指令上限没写错**（它同时放开平移、自旋、跟随）。
